# Guion de presentación — tres minutos

Preparación: `npm ci`, `npm run build`, `npm run preview`; abrir con red una vez para instalar caché. Probar sin red antes de presentar. Alternativa: instalar APK debug. No depender de la consulta NASA en vivo durante la exposición.

**0:00–0:30 · Contexto.** Abrir Itapúa. Explicar que el establecimiento y presupuesto son ficticios, pero el clima histórico es real. Mostrar tierra propia, capital e interés económico.

**0:30–1:00 · Calendario.** Ver práctica actual y dos alternativas. Mostrar fechas y residuos desconocidos. Explicar que el espacio vacío no demuestra suelo desnudo; editar una fecha para mostrar actualización/solapamiento y luego restaurar el caso.

**1:00–1:30 · Evidencia.** Cargar respaldo real del caso. Mostrar año, fuente, cobertura 365/365, hash y umbrales editables. Aclarar que grilla/historia no es sensor/pronóstico. Mostrar serie mensual.

**1:30–2:15 · Diferentes decisiones.** Comparar Itapúa (margen), luego Alto Paraná (alquiler y capital insuficiente), después Caaguazú (más días con cultivo programado a cambio de costo). Mostrar comprador no disponible para maíz. No elegir ganador universal.

**2:15–2:45 · Trazabilidad.** Abrir sensibilidad y caja; explicar pagos agregados. En Datos exportar dossier y CSV. El dossier permite reproducir el mismo plan y respaldo sin Internet.

**2:45–3:00 · Límites.** No hay predicción de cosecha ni validación agronómica local. Próximo paso: asesor y teléfono físico. SMAP/Landsat fueron evaluados y diferidos con motivo documentado.
