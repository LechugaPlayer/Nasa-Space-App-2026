# Cambiar nombre

Editar **product.json** (`name`, `tagline`, `exportFile`) y ejecutar `npm run brand:sync`; corre también antes de dev/build. Actualiza título HTML, ambas interfaces, título al compartir, CSV y strings de Android. Después ejecutar `npm run android:sync` y recompilar el APK.

Nombre provisional: Proyecto Agrícola. Documentación histórica se conserva como antecedente, no como identidad vigente.

No cambiar por marketing `py.rotacion.demo`, la clave `rotacion.android.v1` ni rutas de iconos: son identificadores técnicos heredados; cambiarlos puede crear otra app o perder acceso a planes. Elegir identificador definitivo y migración antes de publicar en tienda. El nombre técnico `rotacion-demo.apk` no controla la marca visible.
